# Java-Swing-Project---Chat-App

Desktop chat application built with Java Swing.

Java Swing desktop chat client. Open the project in an IDE and run `ChatApp`.

## Stack

- Java

## Running

**Desktop application (Java Swing)**

```bash
cd ChatGUI
javac -d out src/CoolChat/*.java
java -cp out CoolChat.ChatApp
```

Requires JDK 8 or newer.
